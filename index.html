⚡ One-time Setup for Global Remarks

  1. Open your Google Sheet → Extensions → Apps Script
  2. Paste the Apps Script code (provided separately) and Save
  3. Click Deploy → New deployment → Web app
  4. Set Execute as: Me & Who has access: Anyone
  5. Copy the Web App URL and paste it in the bottom-left field

Once set up, remarks from any user on any device are saved to your Google Sheet's Remarks tab and loaded in real time.
